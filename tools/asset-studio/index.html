Asset Studio

All-game asset hub — upload / URL / prompt → sprite-gen → PerfectPixel → chunky 4px NEAREST. Local static editor (gear-editor pattern). Ship, Earth, and character art stay user-supplied.

Open an image or URL, set a prompt, pick a destination under assets/, then run the pipeline.

Blocked (user-supplied, not generated here): assets/ship/, assets/earth/, character sprites.
