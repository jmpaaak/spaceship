# Spaceship — Game Design

## 한 문장

지구에서 출발해 가능한 한 멀리 탐험하며 행성 표본을 수집하고, 운석·우주 쓰레기와의 충돌을 피하며, 체크포인트/지구에서 표본을 돈으로 바꾸고 우주선을 강화해 다시 도전하는 모바일 로그라이트.

## 플랫폼과 화면

- 핸드폰 **세로 모드 전용** 플레이
- 내부 해상도 `180×320`, nearest-neighbor 확대
- 지구는 우주의 원점이며, 은하계들이 지구를 중심으로 펼쳐진 매우 큰 원형 우주에 산재한다
- 가상 조이스틱으로 전방향 이동한다 (단순 탭-홀드는 좌우 조종으로 폴백). 키보드는 개발용 보조 입력
- 연료는 비행을 제한하지 않는다. 조이스틱/키 입력 없이 관성으로 움직일 때는 물론, 추력을 쓰는 동안에도 연료를 소모하지 않는다
- 여러 크기의 운석과 우주 쓰레기(빈 캔, 고철 등)가 표류한다. 이들과 부딪히면 행성 충돌과 동일한 파괴·메타 초기화가 일어난다
- 작은 미니맵에 각 은하계의 고리(홈은 태양 중심 태양계 궤도)와 내 위치를 표시한다. 은하에 들어가면 왼쪽 상단에 은하 이름을 표기한다. 우주에 하드 경계는 없고, 차트 반경을 벗어나면 미니맵이 이탈 거리와 지구 방향만 알려 준다

## 원정 루프

1. 지구에서 현재 우주선과 강화를 확인하고 출발한다.
2. 연료 제약 없이 지구에서 멀어진다. 표류하는 운석·쓰레기를 피한다.
3. 멀리 갈수록 희귀하고 가치 높은 행성이 등장한다. 행성은 은하계 안에서만 생성된다.
4. 행성을 스치거나 탐사 범위에 넣어 표본을 얻는다. 일반 행성 탐사는 표본만 지급한다.
5. 행성에 강하게 충돌하면 내구도가 감소한다. 운석·쓰레기에 부딪히면 행성 충돌과 같은 파괴·초기화가 일어난다.
6. 은하 체크포인트에 도킹하면 미정산 표본을 돈으로 바꾸고 은하 고유 장비를 1회 지급한다. 원정은 계속된다.
7. 귀환은 연료 고갈이 아니라 명시적 지구 귀환으로 시작한다. 비행 중 슬롯 머신은 없다.
8. 지구에 안전하게 도착하면 남은 표본을 돈으로 정산한다. 슬롯 머신은 지구 상점 전용이며, 이번 원정에서 가장 최근에 들른 체크포인트 은하의 오즈를 쓴다.
9. 돈으로 새 우주선을 구매하거나 내구도·조종·표본 수익·범용 장비를 강화하고 다시 출발한다.

## 실패와 기록

- 내구도가 0이 되면 우주선이 파괴되어 지구로 귀환하지 못한다.
- 해당 파괴 시점까지 얻은 미정산 표본을 모두 잃는다.
- 보유 돈, 구매 우주선, 강화 상태도 초기화한다.
- 단 하나, 지금까지 가장 높게 올라간 **개인 최고 높이**만 영구 저장한다.
- 안전 귀환과 더 높은 위험을 감수한 상승 사이에 명확한 긴장을 만든다.

## 지구 상점 슬롯

- 명시적 지구 귀환(`returnToEarth`)은 ascending에서 곧장 settlement로 정산한다. 연료 고갈은 트리거가 아니다.
- 비행 중 슬롯 기회는 없다. 슬롯은 지구 상점에서만, 고정 요금으로 돌린다.
- 오즈는 이번 원정에서 가장 최근에 들른 체크포인트 은하에 따라 결정된다. 미탐사는 홈 오즈.
- 슬롯 보상은 즉시 돈으로 확정된다.

## 에셋 정책 — AetherAI only

- 우주선, 지구, 행성, 표본, 충돌 이펙트, 슬롯 심볼, 상점 아이콘, 배경 오브젝트를 포함한 **모든 최종 시각 에셋은 AetherForgeAI/AetherAI 공식 UI 또는 공식 API에서 생성·다운로드한 결과만 사용한다.**
- crawling, scraping, bot, macro로 서비스를 자동 조작하지 않는다.
- 각 에셋은 source URL, terms URL, generation/asset ID, prompt, model/style/settings, 다운로드 시각, 원본 SHA-256, dimensions와 실제 런타임 QA를 기록한다.
- Python/Pillow, Lua 도형, 다른 이미지 생성기 결과는 최종 에셋으로 사용할 수 없다.
- 인증 전 Lua 도형은 충돌·게임플레이를 검증하기 위한 명시적 `DEV PLACEHOLDER`로만 허용하며 최종 미술 완료나 승인으로 간주하지 않는다.

## 첫 플레이 가능한 목표

- `launch → ascending → Earth settlement/shop → relaunch`
- 행성 표본 획득과 가치 증가
- 행성 충돌·내구도 감소·파괴 시 전체 메타 초기화
- 운석·우주 쓰레기 충돌 시 동일한 파괴·초기화
- 연료 제약 없음 (비행 중 연료를 태우지 않음)
- 체크포인트 정산과 지구 상점 전용 슬롯
- 안전 귀환 후 돈 정산과 최소 2종 강화
- 최고 높이 영구 저장
- 세로 `180×320` 실제 LÖVE 캡처와 헤드리스 테스트
